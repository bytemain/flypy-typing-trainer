This Xiaohe XHUP typing trainer is distributed under GPL-3.0.

The portable build includes dictionary data derived from:

  • Repository: kchen0x/rime-crane
  • Data files: xhup.primary, xhup.secondary, xhup.full.code.chars, xhup.full.code.words, xhup.off-table, xhup.whimsicality, xhup.single.code
  • Repository license: GPL-3.0

  • URL: https://www.flypy.cc/ix/ixdata.json
  • Local subset: data/xhup_decomp.js

This app stores practice progress locally in the browser and does not upload data.
