# 小鹤音形练习器

一个本地优先的小鹤音形练习网页，用来练习单字四码、音码与形码的组合、拆字逻辑和字根键位记忆。

线上地址：<https://flypy.cat.ms>

## 功能

- 四码跟打：照着完整四码逐字母输入，正确后自动进入下一题。
- 形码掩码：显示前两码和拆字提示，只输入后两码。
- 拆字提示：展示形码对应的首尾部件，并说明该字根常见还对应哪些部件。
- 中间拆分：可手动开启，遇到三段及以上拆分时，在两个形码部件之间显示中间部件。
- 多音字容错：默认展示第一个读音码，但输入其他可接受读音码也能通过。
- 中文输入法兼容：支持普通英文键入，也支持输入法 composition 上屏当前汉字。
- 本地进度：练习进度保存在浏览器 `localStorage`，不会上传。
- 简码提示：每张卡片上方会标出当前字 / 词的一码 / 二码简码（来自小鹤一简、二简、一简词等码表），帮助记忆「实际打字时其实少敲两键就够」。

## 本地运行

这个项目是静态网页，可以直接打开，也可以用 live server 启动：

```bash
npx live-server --host=127.0.0.1 --port=5500 --no-browser
```

然后访问：

```text
http://127.0.0.1:5500/
```

## 数据

内置码表数据来自 `kchen0x/rime-crane` 仓库中的小鹤音形 `xhup_dicts` 相关码表文件。拆分提示数据来自小鹤音形官方查形数据：

```text
https://www.flypy.cc/ix/ixdata.json
```

本项目只提取练习所需的单字码表与拆字提示子集。为方便再分发，原始码表文件也随包放在：

```text
third_party/rime-crane-xhup/
```

`data/xhup_shortcodes.js` 是从原始码表中提取出的「一码 / 二码简码」索引，供练习界面在每张卡片上展示简码徽章。可用 `python3 tools/build_shortcodes.py` 重新生成。
